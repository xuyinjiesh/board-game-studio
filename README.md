# 桌游工坊 Tablecraft

本地运行的网页桌游工坊，支持从内置示例开始游玩，也可以导入素材、搭建桌面并制作自己的桌游作品。卡牌、骰子、标记和版图均可自由操作，游戏规则由玩家执行。

## 主要功能

- **作品管理**：在作品广场浏览和打开作品，创建、编辑、复制和删除本地草稿，将保存的开局导出为独立作品快照。
- **桌面编辑**：从空白桌面开始，导入图片，添加卡牌、牌堆、骰子、标记和版图，使用公共素材搭建游戏场景。
- **自由游玩**：支持拖放、翻面、旋转、多选、堆叠、洗牌、发牌、搜寻、投骰和数值调整，以及撤销与重做。
- **开局配置**：保存物件摆放、牌序、朝向、初始数值和发牌位置，设置随机开局，并为不同角色保存独立方案。
- **游玩与编辑切换**：游玩时收起编辑工具，编辑时调整桌面与物件属性；支持重新开局和继续已有进度。
- **桌面体验**：提供平移缩放、格点吸附、桌布、操作音效、快捷键自定义和窄屏布局。
- **本地保存与备份**：自动保存草稿和游玩进度，支持包含图片的 JSON 文件导入与导出。

## 快速开始

需要 Node.js 20.11+，无第三方运行时依赖，无需安装包。

```powershell
npm run dev
```

打开终端显示的地址，默认为 [http://127.0.0.1:5173](http://127.0.0.1:5173)。端口被占用时可指定其他端口：

```powershell
$env:PORT = '5174'
npm run dev
```

首页可直接打开内置游戏，也可选择「新建游戏」创建桌面。进入桌面后通过 **Ctrl+E** 切换编辑模式，使用右上角「？」查看操作说明和设置快捷键。

本地服务仅监听本机地址，不会向外部服务上传素材或存档。数据保存在当前浏览器中；更换浏览器、访问地址或端口前，请先导出备份。
