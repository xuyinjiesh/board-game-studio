# 桌间 Tablecraft · 桌游工坊

本地运行的通用网页桌游工坊，首页为展示广场。工坊负责卡牌、骰子、标记、版图等通用操作；游戏的素材、开局、规则及可选专用逻辑属于各自的项目。内置《果丛 / Grove》和《铁盔 / Iron Helm》基础版示例，尚未实现联机、线上社区、自动规则裁判或手牌区。

桌布铺满整个窗口。游玩模式隐藏编辑面板、工具、标题与区域提示，右上角常驻“新一局”，点击后确认再重新开始。按 **Ctrl+E** 切换编辑模式，或将鼠标移到右上角显示编辑入口；按 Esc 也能临时显示入口。编辑模式左侧工具坞可展开初始设置、资产和桌面设置抽屉。抽屉覆盖在桌面上，开关不会改变视角或移动物件；同一时间只展开一个。点击右上角“开始游玩”即可收起全部编辑界面。

## 启动

需要 Node.js 20.11+。无第三方运行时依赖，无需安装包。

```powershell
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。端口被占用时：

```powershell
$env:PORT = '5174'
npm run dev
```

```powershell
npm test       # 核心数据、计分、坐标、资产、导入校验
npm run build # 生成可部署到任意静态服务器的 dist/
```

本地服务仅监听 127.0.0.1；不会向外部服务上传素材或存档。刷新后从「我的工坊」继续项目。每个项目与展示快照存入 IndexedDB，旧版单桌面 localStorage 存档会自动迁移并保留原始备份。浏览器存储按地址和端口区分，换浏览器/端口前请导出项目。保存失败时界面会提示导出。

## 展示广场与项目

- **展示广场**：示例游戏与已展示的本地作品，可搜索名称和介绍、筛选分类。
- **我的工坊**：每个项目独立保留资产、当前桌面、setup、setup 草稿、规则说明和资料。继续项目不会重开牌局。
- **新建游戏**：空白项目中没有果丛卡牌或规则；可导入图片，使用标准 D6、圆形标记及通用网格吸附。
- **项目资料**：编辑模式的「桌面」抽屉可填写游戏名称、介绍、人数、时长与规则。
- **展示到广场**：保存初始设置后，在项目资料中展示作品。展示版本取自已保存的开局；打开作品会建立独立游玩副本，再次展示才更新快照。
- **归档与恢复**：我的项目可归档到「已归档」，随时恢复；撤下展示不删除源项目。

广场目前仅展示这台设备浏览器内的作品；未连接线上社区。导出 JSON 可手动分享，导入时建立新项目，不覆盖现有项目。

## 已实现

- **卡牌**：原画正背面、CSS 3D 翻转、纸边厚度、光泽、投影、悬停抬升、拖动抬起、旋转与微调、多选、堆叠、洗牌、抽取、展开、随机轻微错位、锁定和置顶。
- **骰子**：平面单面显示当前点数、果丛定制骰面 2/3/4/5/6/10、标准 D6、投掷时的平面晃动动画、手动改值、拖动、同选多骰投掷。投掷是视觉动画加随机结果，未接入刚体碰撞模拟。
- **标记**：松鼠、独轮车、通用圆片，以及自定义图片标记。支持颜色、旋转、拖动和复制。
- **版图**：导入 PNG/JPG/WebP，调整宽高、旋转、锁定。独立底层，避免盖住卡牌。
- **工坊**：游玩/编辑模式、空白桌面、自定义卡背、平移缩放、网格、果树格点吸附、三款桌布、合成音效、撤销重做、自动保存、含图片的 JSON 导入导出。
- **界面**：全窗口桌布、无常驻工具的游玩视图、资产/设置抽屉、窄屏布局。编辑面板不挤占桌面，不触发相机重新适配。
- **果丛**：随机九张开局、两张待打牌、备用九张牌、15 颗收获骰、两个特殊标记、原版中文规则阅读、桌面基础分数统计。

## 果丛计分的边界

这是实体桌游的自由桌面。叠牌是否合法、每次收获时增加多少骰值、是否使用松鼠/独轮车、是否需要补牌，都由玩家按规则操作；不会强制阻止非法摆放。

基础得分由骰子中心所在的**最上层正面卡牌**确定，水果颜色匹配才计分。背面、空地、未放到卡牌上的骰子不计分。独轮车在果树上计 15 分。松鼠在卡牌上时扣 1 分，正交相邻且正在计分的骰子再各扣 1 分。请每格放一颗骰子，并使用规则规定的数量；自由桌面允许复制物件，因此不会强制库存上限。食谱奖励需要自行结算。

果丛树格使用正方形的逻辑坐标。原 PDF 裁切后的图片在 2:3 的卡牌框内填充显示，方便 90° 旋转后的精确格点重合。

## 实现与扩展

第一版选择浏览器原生 DOM + CSS 3D + Web Animations + Web Audio。精确的二维叠牌、图片编辑面板、快捷键和无依赖本地部署是当前重点，因此尚未引入 Godot。模型与渲染分开，未来可以把骰子表现替换为 WebGL/物理引擎，或接入 Godot 的场景渲染。

- `src/model.js`：通用物件、坐标/命中、牌堆、setup 与导入校验；不导入任何具体游戏。
- `src/app.js`：通用交互、选择、历史、导入导出、项目资料和 DOM 渲染。
- `src/games/grove.js`：果丛的资产、默认开局、骰面、标记、规则、果树吸附和计分；通过游戏模块接口接入。
- `src/projects.js`：游戏注册表、项目复制、旧存档迁移、展示快照。
- `src/project-store.js`：IndexedDB 项目库与展示库。
- `src/plaza.js` / `src/plaza.css`：本地展示广场、搜索筛选、我的工坊与归档恢复。
- `src/style.css`：工坊界面、桌布、纸牌双面与抬升、单面骰子和响应式布局。
- `src/audio.js`：本地 CC0 实录音效，按卡牌、骰子、木质标记、纸板和版图区分；预加载与缓存、随机变体、并发限制及即时静音。
- `scripts/`：本地服务、静态打包、PDF 图片裁切脚本。
- `tests/`：核心行为回归检查。

物件使用稳定 ID，牌堆保存有序资产 ID；手牌区未来应作为独立 zone 加入，管理其子物件顺序和插入/删除动画，不要把它混入自由桌面拖拽。本版的“待打出的牌”仅为普通桌面摆放，没有手牌区逻辑。

## 编写初始设置（setup）

进入编辑模式，点击左侧「初始设置」打开抽屉。可以「从当前桌面生成」配置，也可以载入「项目默认设置」，然后直接编辑 JSON。

- `name`：初始设置名称。
- `objects`：物件列表，支持卡牌、牌堆、骰子、标记和版图；字段与桌面物件相同，无需 ID。位置为物件中心的 `x / y`，角度为 `rotation`，层级为 `z`。图片使用资产 ID，抽屉中可查阅编号。牌堆 `cards` 数组的末项为顶牌。
- `randomizeCards`：每次开局将所有卡牌重新随机分配到单牌位置和牌堆中，保留牌堆数量；适用于果丛的 18 张牌分配。
- `shuffleDecks`：分别洗匀各牌堆；`rollDice`：随机选择每颗骰子的初始骰面。三个选项均使用 `true / false`。

未保存的草稿按项目保留，刷新或切换项目后仍可继续编辑。「保存初始设置」才将草稿用于新局，不改变进行中的桌面。「试运行」应用当前草稿，可撤销；游玩界面的「新一局」使用已保存的 setup。配置会自动保存，也会随桌面 JSON 导出、导入。无效配置会在编辑框下显示错误，不会应用。停用自定义 setup 后恢复该项目的默认开局；空白项目默认为空桌面。当前使用声明式配置，不执行 JavaScript。

桌面默认不随左键空白拖动平移；左键用于区域框选。普通滚轮不改变视角；Ctrl + 滚轮以鼠标位置为中心缩放。鼠标悬停在数值 token 上滚动可逐次增加或减少 1，保留游戏数值上下限，可撤销并自动保存。按住空格后左键拖动、或中键拖动进入抓手平移，在物件上同样有效；空格不再打开卡牌详情，中键轻点不再旋转卡牌。选中物件保持与悬停相同的浮起效果，拖动时进一步抬起。选框仅在框选过程中显示，松开后隐藏，选中或移动部件均无外框。框选忽略已锁定物件和底层版图；多件移动保留相对位置，不逐件吸附。Esc 取消正在进行的框选或移动。


## 添加新的内置示例

在 `src/games/` 新增游戏模块，并加入 `src/projects.js` 的 `examples` 注册表。模块可提供 `create()` 工厂、标题与介绍、骰子/标记模板、规则数据，以及可选的 `onDrop()` / `score()`。游戏工厂返回通用 session，将全部图片资产与 `initialSetup` 写入项目。没有注册模块的自建项目使用通用行为；导入文件中的文本不会作为代码执行。


## 铁盔 · 基础版

展示广场选择「铁盔 · 基础版 → 从示例开始」，先选择四位角色之一。开局自动配置其生命、能量、金币、口粮、专精技能和两件初始装备。法蓬没有初始武器，可在冒险手册的「装备 / 技能牌库」中使用初始金币购买；索塔布须在该牌库自选两瓶炼金术初始药剂，再探索。

- 只包含基础版 104 张游戏卡牌：3 首领、4 角色、16 地城、18 敌人、18 战利品、10 药剂、9 剧情、12 技能、14 初始装备。另有地图与道德轨道，以及按照提供版本的祝福图案拆出的 12 枚双面祝福。未加入扩展角色、扩展地图或随机事件。
- 「抽两张门」保持两张背面，任意选择先看的门；保留时执行第 1 段，放弃换门则执行第 2 段。按牌面完成效果后点击「结算完毕」。每层严格记录 8 回合；未查看的门和丢弃的门保持背面。
- 「换层结算」重洗 16 张地城、消耗口粮（没有则扣 3 生命）、增加每两点中毒对应的一点中毒、前进一层并抽剧情。若该消耗导致死亡，停止在死亡步骤。
- 「冒险手册」调整生命、能量、金币、口粮、中毒、道德、层数、回合、眼睛及敌人生命。生命与能量受角色初始上限限制；道德为 −5 至 +5。
- 手册可抽取敌人、战利品、药剂、剧情和背面祝福。选中卡牌后用「归档选中的卡牌」放入对应弃牌区：剧情累计印刷的眼睛；敌人进入未花费经验的墓地。技能按专精消耗 3 或 5 张墓地敌人，移入「已花费经验」墓地，仍保留供最终首领统计。
- 所有卡牌可自由拖动、翻面、放大、合堆和洗牌。3 颗标准 D6 用于战斗；敌人生命用独立计数标记记录。右键看大牌面，D 投掷选中骰子。背面卡的可访问名称和详情标题不泄露牌名。
- 角色选择、资源、探索阶段、牌堆顺序、墓地与技能均随桌面自动保存、撤销和导出。刷新后从「我的工坊」继续；新一局按所选角色的初始设置重新洗牌，牌组之间不会混洗。

**规则执行范围：**这是带冒险辅助的自由桌面。战斗掷骰和伤害、敌人能力、装备槽位与负重、商人交易、消耗品、技能特殊效果、剧情选项、祝福奖励、首领选择和最终胜负/计分由玩家按牌面结算。归档敌人表示玩家已完成战斗；不会自动发放战利品。直接使用通用桌面操作修改/合并专用牌堆会改变其结构；误操作可撤销。
