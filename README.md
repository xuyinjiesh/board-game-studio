# 桌游工坊 Tablecraft

本地运行的通用网页桌游工坊，首页为作品广场。工坊负责卡牌、骰子、标记、版图等通用操作；游戏的素材、开局、规则及可选专用逻辑属于各自的项目。内置《果丛 / Grove》和《铁盔 / Iron Helm》（含可选扩展）示例，尚未实现联机、线上社区、自动规则裁判或手牌区。

桌布铺满整个窗口。游玩模式隐藏编辑面板、工具、标题与区域提示，右上角常驻“新一局”，点击后确认再重新开始。按 **Ctrl+E** 切换编辑模式，或将鼠标移到右上角显示编辑入口；按 Esc 也能临时显示入口。编辑模式左侧只有资产和桌面设置入口，选中物件会在右侧显示开局属性。面板覆盖在桌面上，开关不会改变视角或移动物件。点击右上角“开始游玩”即可收起全部编辑界面。

## 启动

需要 Node.js 20.11+。无第三方运行时依赖，无需安装包。

```powershell
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。端口被占用时：

```powershell
$env:PORT = '5174'
npm run dev
```

```powershell
npm test       # 核心数据、计分、坐标、资产、导入校验
npm run build # 生成可部署到任意静态服务器的 dist/
```

本地服务仅监听 127.0.0.1；不会向外部服务上传素材或存档。刷新后从「本地草稿」继续项目。每个草稿与作品广场快照存入 IndexedDB，旧版单桌面 localStorage 存档会自动迁移并保留原始备份。浏览器存储按地址和端口区分，换浏览器/端口前请导出项目。保存失败时界面会提示导出。

## 作品广场与本地草稿

首页只有两个入口，没有宣传横幅、重复分类或归档分区。

- **作品广场**：内置示例和已导出的作品。可直接游玩或编辑；重复打开会复用已有草稿，不再不断创建副本。
- **本地草稿**：所有本地项目（包括旧版已归档项目），按最近保存排序；点击「编辑草稿」恢复原始开局。
- **新建游戏**：从空白桌面开始，导入图片、添加牌堆与标记，直接摆放。
- **保存草稿**：顶部按钮或 Ctrl+S，直接将编辑桌面的摆放和各物件开局规则保存在当前浏览器。修改也会自动保存，不需要另行生成 setup。
- **导出到作品广场**：顶部按钮将当前已保存的开局复制为独立快照。继续修改草稿不改变作品广场版本；每次导出遇到同名作品（包括自己的旧版本和内置示例）都会提醒，可覆盖、改名导出或取消；确认覆盖后作品广场只保留一份。撤回作品广场不会删除草稿。
- **删除草稿 / 撤销发布**：本地草稿卡片底部可删除草稿，作品广场作品底部可撤销发布。确认弹窗会说明操作范围；删除草稿不会删除作品广场版本，撤销发布不会删除草稿。操作后页面上方会出现「撤销」，可恢复最近一次操作，刷新页面后不再提供此恢复入口。删除时会一并移除旧版隐藏的同名重复记录，避免它们重新出现。
- **文件备份**：桌面设置中的「下载备份文件」导出含图片的 JSON；首页「导入文件」建立独立本地草稿。

作品广场目前仅展示当前浏览器内的作品，尚未连接线上社区。作品广场与草稿分别按名称去重，旧的同名记录合并显示最近保存的一份；原始历史记录保留，不直接删除。新建同名草稿会打开原草稿；改名撞名会提醒另取名称；同名文件导入会被阻止，避免覆盖已有草稿。名称比较会忽略首尾空白、重复空格、全半角及字母大小写。

## 已实现

- **卡牌**：原画正背面、CSS 3D 翻转、纸边厚度、光泽、投影、悬停抬升、拖动抬起、旋转与微调、多选、堆叠、洗牌、抽取、展开、随机轻微错位、锁定和置顶。
- **骰子**：平面单面显示当前点数、果丛定制骰面 2/3/4/5/6/10、标准 D6、投掷时的平面晃动动画、手动改值、拖动、同选多骰投掷。投掷是视觉动画加随机结果，未接入刚体碰撞模拟。
- **标记**：松鼠、独轮车、通用圆片，以及自定义图片标记。支持颜色、旋转、拖动和复制。
- **版图**：导入 PNG/JPG/WebP，调整宽高、旋转、锁定。独立底层，避免盖住卡牌。
- **工坊**：游玩/编辑模式、空白桌面、自定义卡背、平移缩放、网格、果树格点吸附、三款桌布、合成音效、撤销重做、自动保存、含图片的 JSON 导入导出。
- **界面**：全窗口桌布、无常驻工具的游玩视图、资产/设置抽屉、窄屏布局。编辑面板不挤占桌面，不触发相机重新适配。
- **果丛**：随机九张开局、两张待打牌、备用九张牌、15 颗收获骰、两个特殊标记、原版中文规则阅读、桌面基础分数统计。

## 公共素材

编辑模式打开「资产 → 公共素材」，可按牌位、骰子、标记筛选并点击添加。所有项目共用：固定牌位、4 款 Kenney 图像骰子、原有 4 色标准骰、36 款棋子/米宝/圆片/旗帜/筹码，以及可改色圆形标记。骰子支持投掷和切换骰面，图片标记保留原图配色；「游戏素材」和「公共素材」为独立入口。游戏素材按卡牌、骰子、标记、版图分类，仅展示当前游戏的专用和导入素材；公共素材只展示工坊通用组件。导入图片后自动进入对应的游戏素材分类。组件可保存、复制并随存档导入导出。

新增图像来自 Kenney Boardgame Pack v2，采用 CC0，可免费商用、修改与再分发。来源与原始授权见 [公共素材说明](public/assets/shared/README.md)。固定牌位为工坊组件。

## 果丛计分的边界

这是实体桌游的自由桌面。叠牌是否合法、每次收获时增加多少骰值、是否使用松鼠/独轮车、是否需要补牌，都由玩家按规则操作；不会强制阻止非法摆放。

基础得分由骰子中心所在的**最上层正面卡牌**确定，水果颜色匹配才计分。背面、空地、未放到卡牌上的骰子不计分。独轮车在果树上计 15 分。松鼠在卡牌上时扣 1 分，正交相邻且正在计分的骰子再各扣 1 分。请每格放一颗骰子，并使用规则规定的数量；自由桌面允许复制物件，因此不会强制库存上限。食谱奖励需要自行结算。

果丛树格使用正方形的逻辑坐标。原 PDF 裁切后的图片在 2:3 的卡牌框内填充显示，方便 90° 旋转后的精确格点重合。

## 实现与扩展

第一版选择浏览器原生 DOM + CSS 3D + Web Animations + Web Audio。精确的二维叠牌、图片编辑面板、快捷键和无依赖本地部署是当前重点，因此尚未引入 Godot。模型与渲染分开，未来可以把骰子表现替换为 WebGL/物理引擎，或接入 Godot 的场景渲染。

- `src/model.js`：通用物件、坐标/命中、牌堆、setup 与导入校验；不导入任何具体游戏。
- `src/app.js`：通用交互、选择、历史、导入导出、项目资料和 DOM 渲染。
- `src/games/grove.js`：果丛的资产、默认开局、骰面、标记、规则、果树吸附和计分；通过游戏模块接口接入。
- `src/projects.js`：游戏注册表、项目复制、旧存档迁移、展示快照。
- `src/opening-editor.js`：物件级开局选项、发牌位置和牌序调整界面。
- `src/project-store.js`：IndexedDB 项目库与展示库。
- `src/plaza.js` / `src/plaza.css`：作品广场、本地草稿、搜索与已有草稿复用。
- `src/style.css`：工坊界面、桌布、纸牌双面与抬升、单面骰子和响应式布局。
- `src/audio.js`：本地 CC0 实录音效，按卡牌、骰子、木质标记、纸板和版图区分；预加载与缓存、随机变体、并发限制及即时静音。
- `scripts/`：本地服务、静态打包、PDF 图片裁切脚本。
- `tests/`：核心行为回归检查。

物件使用稳定 ID，牌堆保存有序资产 ID；手牌区未来应作为独立 zone 加入，管理其子物件顺序和插入/删除动画，不要把它混入自由桌面拖拽。本版的“待打出的牌”仅为普通桌面摆放，没有手牌区逻辑。

## 直接编辑开局（setup）

进入编辑模式，添加卡牌、牌堆、骰子、token 和版图，直接拖动到开局位置。编辑时点击牌堆选择它，拖动会移动整叠；游玩时默认拖动顶牌，长按牌堆打开菜单。

选中物件会在右侧显示属性和「开局设置」，也可右键打开。没有独立 setup 抽屉、采用摆放步骤或 JSON 配置界面。

- **每个牌堆的牌序**：固定顺序 / 每局随机洗牌。各牌堆独立，不混合不同种类的牌。展开「调整牌序」可逐张向牌顶或牌底移动，列表首项为顶牌。
- **卡牌、牌堆和 token 的面**：固定面 / 每局随机正背面。固定时选择正面或背面；自定义 token 可导入背面图片。
- **骰面**：保留当前骰面 / 每局随机骰面。当前数值通过属性中的骰面按钮调整。
- **token 数值**：属性中填写初始数值，保留专用游戏的数值范围。

位置、角度、锁定、牌序、朝向和初始数值都会直接保存到本地草稿。点击「开始游玩」时按每个物件的随机设置生成一局；「新一局」重新应用保存的开局。游玩进度的自动保存不会覆盖原始 setup，切回编辑模式或编辑本地草稿时恢复原始摆放。需要继续游玩时使用游玩进度入口。

### 初始发牌位置

选中一个牌堆，在右侧点击「设置初始发牌位置」。拖动新出现的虚线牌位，设置名称、来源、抽取数量、发牌顺序、正背面和摆放方式。可以展开为单牌（支持间距），也可以组成新的牌堆；一个牌堆可以供多个牌位取牌。

每局先加载开局方案，独立洗牌，再按发牌顺序从小到大取牌（相同顺序按创建先后）。牌从来源牌堆移出，多个牌位合计不会超出库存。来源缺失、发牌数量过多或展开位置超出范围时会提示并阻止应用，不会重复或凭空复制卡牌。「发完后移除空堆」可隐藏已经分配完的开局牌库。

发牌位置仅存在于编辑界面；游玩时替换为实际卡牌或牌堆。返回编辑时恢复牌位和完整来源牌库。删除来源牌堆也会移除对应牌位，均可撤销。复制来源牌堆与它的牌位时会一起重建关联；已经关联牌位的来源不能直接展开散牌。

《果丛》的默认开局已使用通用牌位：18 张牌的来源牌库洗匀，分到 3 张初始单牌、本局剩余 6 张和备用 9 张。编辑保存后仍会在每局重新抽取；旧版全局随机分配设置也会保留。

### 角色开局方案

左侧「开局方案」可复制当前摆放为角色方案、切换编辑、重命名或移除。每个方案独立保留完整摆放、装备、token 数值与发牌规则，图片资产共用；切换前自动保存当前编辑。最多 20 个方案，移除可撤销，至少保留一个。

有多个方案时，「开始游玩」「新一局」和从作品广场首次进入游玩都会先选择角色，再生成卡牌；取消首次选择会返回作品广场，继续游玩时重新选择。游玩中重选角色不会修改草稿，编辑方案会恢复它的原始摆放。所有方案随本地草稿、文件备份和作品广场快照一起保存。

《铁盔》提供四位角色的可编辑初始方案，各自保留对应生命、能量、金币、口粮、装备和技能。旧存档迁移会保留当前角色的自定义开局和游玩进度。

旧版 JSON setup 仍可导入。没有执行任意 JavaScript 的入口。

桌面默认不随左键空白拖动平移；左键用于区域框选。普通滚轮不改变视角；Ctrl + 滚轮以鼠标位置为中心缩放。鼠标悬停在数值 token 上滚动可逐次增加或减少 1，保留游戏数值上下限，可撤销并自动保存。按住空格后左键拖动、或中键拖动进入抓手平移，在物件上同样有效；鼠标悬停部件后上滚顺时针、下滚逆时针旋转；鼠标中键仅用于平移桌面。选中物件保持与悬停相同的浮起效果，拖动时进一步抬起。选框仅在框选过程中显示，松开后隐藏，选中或移动部件均无外框。框选忽略已锁定物件和底层版图；多件移动保留相对位置，不逐件吸附。Esc 取消正在进行的框选或移动。


## 添加新的内置示例

在 `src/games/` 新增游戏模块，并加入 `src/projects.js` 的 `examples` 注册表。模块可提供 `create()` 工厂、标题与介绍、骰子/标记模板、规则数据，以及可选的 `onDrop()` / `score()`。游戏工厂返回通用 session，将全部图片资产与 `initialSetup` 写入项目。没有注册模块的自建项目使用通用行为；导入文件中的文本不会作为代码执行。


## 铁盔 · 基础版与可选扩展

作品广场打开「铁盔」，或在游玩中点「新一局」，依次选择扩展、当前冒险和地城牌组，再选角色。默认不勾选扩展，仍为原来的基础版；「仅基础版」清空选择，「全部加入」勾选全部模块。点击角色之前不改变当前牌局。继续游玩会恢复存档，不重新选择扩展。

支持素材中的 16 个可选包：7 个冒险包（绝望巢穴、焦黑深窟、加尔诺克的迷宫、水晶洞窟、余烬王座、玛莉西亚的藏身处、佐加尔之塔），战利品与传说、野兽与重担、领域与遗迹、腰包扩展、孤独巨魔酒馆、哀嚎深渊、铁窖、随机事件，以及民间扩展「贫血之地」。新增 353 份正背面卡牌与说明资产。

- 可同时勾选多个包。补充装备、药剂、技能等进入各自牌堆；环境、灾厄、神器、随从、星宿、随机事件、说明卡与备用内容在牌垫下方独立摆放，并显示名称。
- 「本局冒险」从基础冒险及已勾选的冒险包中选一项。冒险包的敌人、剧情、首领作为本局对应牌组，其余冒险包的这些卡牌进入备用区。已选包的装备、技能和战利品供本局使用。这是方便自由组合的开局配置，战役推进及特殊规则按该包说明执行。
- 「本局地城牌组」可选基础的 16 张地城，或勾选哀嚎深渊后改用其 18 张地城。两套不会混洗，另一套进入备用区。
- 勾选相应包后，扩展角色加入开局选项；全选时共有 23 个预设角色（含基础 4 个），按印刷属性、初始装备及技能布置。个别跨包初始装备会作为角色必需品一并提供，角色说明中有提示。铁窖的 8 张种族 / 职业双面牌作为组件放在扩展区，由玩家自由组合、叠加属性。
- 规则仍由玩家执行：装备槽位、特殊负重、商人交易、消耗品、技能、剧情、祝福、随从、灾厄、环境、神器、星宿、首领与胜负计分均按原牌面和附带说明结算。腰包的神器需同时使用领域与遗迹。民间扩展单独标注，默认关闭。
- 相同扩展配置保留已编辑的开局；更换配置会重建内置角色的默认方案，自建角色方案保留。选择配置与角色、牌序、桌面、资源、各角色开局一同自动保存、复制和导出；可用撤销恢复上一局。

桌面使用 780 × 320 中文大牌垫，默认锁定为底图。生命、能量、金币、口粮、中毒、层数、道德和敌人生命使用方形标记，拖至对应刻度或在标记上滚轮调整。顶部中央仅保留游戏名与「规则手册」；桌面操作使用通用牌堆、发牌、搜寻、洗牌、翻面和拖放，不增加自动规则裁判。

基础版原有 104 张游戏卡牌、祝福及轨道资产保持不变。`scripts/extract-iron-helm.py` 提取基础卡牌，`scripts/extract-iron-helm-dlc.py` 从综合排版与随机事件 PDF 提取扩展，`scripts/extract-iron-helm-mat.py` 提取牌垫与标记。每张扩展记录来源页、位置、包和类别，背面按双面长边镜像配对。

完整基础规则及附录保存在 `public/assets/iron-helm/`，来源为 [Grey Gnome Games 官方规则](https://greygnome.com/wp-content/uploads/2018/11/iron-helm-rules.pdf) 与 [官方附录](https://greygnome.com/wp-content/uploads/2018/11/iron-helm-appendix.pdf)。扩展使用提供素材中的双面说明卡。游戏、美术及中文素材的权利归各自作者，沿用原素材标注。

游玩模式右下角常驻「回到初始视野」，按已保存的开局布局恢复缩放与居中；只调整视角，不移动物件或重开牌局。编辑模式的「适应桌面」仍按当前物件分布计算。

卡牌或可移动牌堆拖到现有牌堆中央时，会显示「松手加入牌堆」，松手后直接合入，无需按 Alt。目标牌堆的位置、名称、尺寸及发牌设置保持不变，卡牌当前的正背面也会保留，归入后可正常发牌、搜寻和洗牌。拖到单张卡牌中央仍只吸附对齐，按住 Alt 可合成新牌堆；边缘重叠保持自由摆放，Esc 取消拖动。

牌堆默认操作顶牌：点击选择，拖动取出顶牌，双击或 F 翻转顶牌；其余牌的顺序和正背面保持不变。按住牌堆约半秒后弹出菜单，仅显示「发牌 D」「搜寻 S」「洗牌 R」。菜单不再提供顶牌／整堆切换，也不再使用 Q 切换模式；点击菜单外或按 Esc 收起。长按不会发牌或移动整叠。

搜寻窗口按顶牌到底牌的顺序展示全部牌，点击「取出这张牌」可取出指定卡牌，其余牌序不变。发牌优先使用编辑器设置的目标；没有指定目标时发到牌堆右侧。发牌后保持整堆选中，可以连续按 D。普通卡牌的 R 仍用于旋转，骰子的 D 仍用于投掷；快捷键也可以在帮助窗口中自定义。

发牌、搜寻取牌、拖动和洗牌都保留每张牌当前的正背面。编辑模式下拖动牌堆仍移动整叠，用于安排开局。Esc 或取消指针可撤销当前拖动。

游玩页右上角的「？」可查看操作说明，并修改键盘快捷键或恢复默认。快捷键保存在当前浏览器，所有游戏通用；重复组合与基础操作保留键会提示冲突。编辑桌面、新一局与帮助入口使用统一布局。

点击发牌：在编辑模式选中牌堆（或会生成牌堆的初始牌位），在「点击发牌位置」中点选桌面目标。虚线标记可拖动，坐标与角度可精确修改。游玩时点击牌堆发一张到目标，直接拖动顶牌仍可自由摆放；未配置目标时会提示且不消耗牌。目标随开局方案、存档和作品一起保存。

点击发牌位置的「发牌到」现支持：指定牌堆、来源牌堆右边/下面/中央/上面/左边，以及自定义桌面位置。方向位置随来源牌堆移动，可设置间距；指定牌堆将顶牌直接加入目标，引用会在重新开局后保留。目标被删除、锁定或已满时提示原因，来源不扣牌。

牌位和牌堆是所有游戏共用的组件：固定位置、容量、尺寸、吸附、顶牌与整堆模式、归堆、发牌、搜寻、洗牌、正背面保存及编辑辅助显示均使用同一套实现。开局发牌生成的牌堆也沿用这些设置。果丛默认本局和备用牌堆使用通用固定牌位，旧存档只补齐缺失的默认设置，保留用户明确设置的选项。通用牌位收牌优先于游戏的落牌规则；果丛的果树格点吸附仅处理果园卡牌叠放。


## 口袋骑士 / Pocket Paladin

作品广场新增《口袋骑士》，使用四页 PNP。包含两张双面地图、红紫骑士、双面能力与状态卡、16 枚敌人／盟友／技能圆片、三个水晶转盘、水晶源，以及分区桌垫。红／紫骑士各有 A／B 地图出发方案；开局独立洗匀怪物和法师，发放三个游荡敌人和三个展示项，保留全部 16 枚圆片。

默认按简单难度（5 轮、城堡 2 塔楼敌人 + 1 游荡敌人）说明。红骑士开局从展示区手动取一枚圆片作为技能，再手动补满展示区。紫骑士开局有一个盟友容量。回合、轮次、等级、创伤和能力位置均使用空白指示物，拖近对应格子时吸附到卡面中心，用位置记录状态。水晶计数仍可用滚轮调整并同步转盘。双击水晶源片，或选中后按 D，可带投掷动画和音效随机转向六个方向之一；可撤销并随进度保存。没有专用操作栏，获取技能、招募盟友、补充及更新展示区全部由玩家自由拖放、翻面与发牌完成。

这是自由操作桌面：行动路线与次数、移动费用、地形、探索翻图、战斗、招募／升级费用、耗竭恢复、创伤惩罚、城堡守军与胜负均按完整规则手动执行。六档难度见游戏内手册。创伤轨道最左端为 10。旧存档和角色方案中的轨道／能力标记自动去除过期数字，保留原位置。水晶转盘可手动旋转，但只有调整水晶数值标记会同步转盘。

作者公开的英文规则 1.5 已附于 `public/assets/pocket-paladin/rules-en.pdf`（40 页），来源为作者在 The Game Crafter 规则书页面提供的 `https://tinyurl.com/pocket-paladin-rules`，同时保留BGG 规则链接。素材提取脚本 `scripts/extract-pocket-paladin.py` 可从 PNP PDF 重建 25 份双面组件和桌垫；素材与规则权利属于 Joe Klipfel / Mythfield Games。未包含素材中没有的额外奖励地图与参考卡；完整地点、敌人和技能说明可在英文规则中查阅。


### 口袋骑士的地图叠放与六角格

两张地图左右对齐，下方地图压在上方地图之上，使两张图的两格草地衔接。骑士从底边中央的半格起步，游荡敌人按旗帜所在六角格的中心布置。开启「地图六角格吸附」后，骑士与敌人拖入地图会落在六角格中心；地图的旋转、尺寸和正背面均计入定位，黑色边角和被上层地图遮住的格子不吸附。地图附近按正确间距拖放也会自动对齐上下叠放。游戏素材在地图以外自由摆放，不再使用通用 40 像素方格吸附。

旧存档及角色开局中的原始默认摆放会自动修正；已自行移动或调整尺寸的地图保留，可拖近另一张地图使其对齐，或在「新一局」选择修正后的角色方案。


轨道／能力卡的吸附点依据原图测量，并以卡牌自身坐标计算。各指示物只吸附到自己的轨道（创伤对应心形格），能力指示物可落在九个能力方格中心；旋转、移动、缩放或翻到另一角色面后仍按卡面定位。只辅助摆放，不检查行动路径或规则合法性；在格子以外仍可自由放置，关闭「卡面格点吸附」可完全自由摆放。红骑士默认能力起点为中间左侧星标格，紫骑士为下方第二个星标格。


### 拖放到牌堆底部

拖动一张卡牌或敌人圆片到牌堆中心：直接松手加入牌堆顶部；保持按住并停留约 0.8 秒，边框变绿、提示变为「松手放到牌堆最下方」后再松手，则插入底部。移出牌堆或换一个牌堆会重新计时。牌面朝向按原样保留，敌人／盟友圆片可先用 F 翻到需要的一面再归堆。支持空堆和移动整堆，仍受锁定、容量及来源牌库限制；单张固定牌位不提供底部选项。操作可撤销并随桌面保存。


### 悬停或按住物件滚轮调值

鼠标悬停在骰子或有数值的指示物上，上滚增加、下滚减少；也可按住鼠标左键操作；鼠标稍微移开物件或一边拖动也会调整最初拿住的那一个。骰子按实际可用骰面递增／递减（例如果丛的 6 下一档是 10），到最大／最小值停止。水晶数值指示物遵守 0–5 上限并同步水晶片转向；空白位置标记不产生数值。连续按住期间的调整与移动合为一次撤销，Esc 或取消拖动恢复原状态。未按住时原有的悬停指示物滚轮调值仍可用；Ctrl+滚轮在未拖动物件时缩放桌面。


鼠标悬停在无数值的可旋转部件上时，上滚顺时针、下滚逆时针；默认每档 90°，口袋骑士的水晶片每档 60°。水晶计数随对应水晶片的转向更新。骰子和数值指示物优先增减值；空白指示物保持空白。旋转期间仍可拖动，连续操作合为一次撤销，Esc 恢复原状态。鼠标中键仅用于平移视角；R / Shift+R 旋转快捷键保留。


水晶片按 60° 对齐六个方向，R、角度输入和滚轮旋转均使用相同的对齐与计数同步逻辑。旧存档中倾斜的水晶片会按水晶计数恢复对应方向；水晶源取最近的 60° 方向。水晶片拿起时保持平面显示，避免纸牌的三维倾斜效果造成误读。
