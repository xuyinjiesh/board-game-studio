三张地图及六位角色面板从 PnP PNG 提取，规则 PDF 为原始文件副本。标准 52 张扑克牌及牌背由项目脚本自行绘制，未使用第三方扑克牌插画。

提取脚本：`scripts/extract-52-realms.py`。详细组件、使用方式和规则辅助范围见 `docs/games/52-realms.md`。
