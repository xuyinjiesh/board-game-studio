# For Northwood! / 为了北境森林

Extracted from the user's local Chinese `PNP.pdf` (16 pages). The supplied
English `For_Northwood_-_Rules_20220827.pdf` (16 pages) is copied as
`rules-en.pdf`. Game art, text, rules and translation remain the property of
their respective authors; inclusion does not grant a new redistribution license.

Components: 32 dialogue cards, 24 characters, 8 fiefs, 1 visiting / medal card
(65 double-sided cards). The advanced challenge booklet was not supplied.

Rebuild with `scripts/extract-for-northwood.py <source-directory>` using
pypdfium2 and Pillow. The script uses the printed 63 × 88 mm trim boxes,
inset by one PDF point to remove crop marks. Fief and visiting backs are
paired by horizontally mirrored columns for long-edge duplex printing.
