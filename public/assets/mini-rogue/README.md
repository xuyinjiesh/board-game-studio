# Mini Rogue 中文 PnP 素材

来自用户提供的「迷你游侠中文版  带扩  含中规」。原作者 Paolo Di Stefano、Gabriel Gendron；出版方 Nuts! Publishing。美术、游戏规则及汉化权利归各自权利人。

由 `scripts/extract-mini-rogue.py` 从卡片 PDF 与板件 JPG 提取，源文件未修改。82 项游戏资产、24 个原图骰面，以及一份原始中文规则。扩展按照卡面右下图标划分为诅咒深渊、古神、死亡蝙蝠与赃物贩子、狼与熔炉，默认仅启用基础版。

奖励／鬼魂为一张双面参考卡；重复印刷格不额外计为遭遇牌。板件角色和战役区域已转为正常阅读方向。详见项目文档 `docs/games/mini-rogue.md`。
