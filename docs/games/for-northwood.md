# 为了北境森林 / For Northwood!

[返回文档目录](../README.md)

## 组件与开局

作品广场可直接开始《为了北境森林》。素材来自用户提供的中文 `PNP.pdf`（16 页）和英文 `For_Northwood_-_Rules_20220827.pdf`（16 页），包含 65 张双面组件：四种花色各 1–8 的 32 张对话牌、24 张角色牌、8 张目标为 0–7 的领地牌，以及正面箭头／背面奖牌表的拜访指示牌。原材料没有进阶挑战册，本次未包含挑战模式。

提供两个可独立编辑和保存的开局方案：

- **入门局**：四位骑士作为固定盟友，八位女王与国王随机分配至领地；带额外皇冠的 12 位角色留在备用牌堆。
- **完整局**：每种花色从六位角色中随机选择一位盟友、两位领主；八位领主再随机分配至领地。其余 12 位角色按花色置于右侧备用区，不参与本局。

备用牌堆紧接右侧「备用角色」标题下方摆放：入门局为一堆 12 张，完整局为两行两列、每堆 3 张。旧进度及各保存开局中仍在原始位置的备用牌堆会自动移入此区域；已手动移位或旋转的摆放保留。

两种开局均将 32 张对话牌独立洗牌，正面发出八张手牌，剩余 24 张作为背面朝上的牌库。领地从左到右按 0–7 排列，领主向上错开，让领地的目标数字可见。每次重新开局会重新随机选择／分配角色及手牌；若将角色来源牌堆改为固定牌序，则保留其固定选择和分配。

手牌在屏幕底部独立显示，以轻微弧度相互叠放，不随桌面缩放或平移。悬停／键盘聚焦会抬起并显示完整牌面，点击可选中，拖出即可自由落牌；也可将对话单牌或牌库顶牌拖回手牌区，在目标位置插入。拖动手牌可调整顺序，亦可选中后按 `Alt+← / Alt+→` 调整。下方「花色」「点数」按钮整理手牌，中央显示 `当前张数 / 8`；8 为参考值，角色能力允许的额外摸牌仍可放入。右键放大与 F 翻面继续可用。归属、顺序、正背面支持自动保存、撤销与恢复。旧存档仅迁入仍位于原开局手牌行的对话牌，不改变已打出的单牌或牌堆。

## 操作与辅助

选择未拜访领地，将拜访指示牌移到其上方。从对话牌库拖出顶牌至弃牌堆，按 `F` 翻至正面，作为领主陈述。手动从八张手牌中拖出回应：赢得的回应进入得分堆，其他回应进入弃牌堆，领主陈述始终留在弃牌堆。盟友能力使用后手动旋转 90° 标记耗竭，替补角色叠在盟友上方。桌面不显示额外的游戏专用按钮栏。

拜访结果直接用卡牌记录：失败按规则移除领主并翻转领地；成功将领主略向下移。无需额外圆标记，旧存档和各开局中的状态圆标记会自动清理。目标 0–7 的星数依次为 `4、3、2、1、1、2、3、4`，按友好领地牌手动累计；领主被征用或移除后，已获得的星数保留。标准、进阶、理想主义胜利门槛分别为 16、18、20 星。

开启「卡牌边缘吸附」后，拖近相邻卡牌会显示金色对齐线和落点轮廓，松手对齐左、右、上、下边缘，或使两牌相邻的边缘贴合。只对齐接近的方向：领主与领地的左右边缘可对齐，同时保留上下错位以露出领地信息。吸附范围随缩放调整，旋转和不同尺寸均纳入计算；锁定的卡牌也可作为参照。手牌不参与桌面吸附，放入固定牌堆仍优先入堆。编辑与游玩均可使用，关闭吸附后可完全自由摆放。

拜访结束后，按规则手动收回全部 32 张对话牌并洗牌，再将 8 张牌拖入手牌区并翻至正面。长按牌堆可打开通用牌堆菜单使用洗牌。自行移除本次替补、重置盟友，保留已记录的领地结果。

编辑模式的「桌面设置 → 游戏规则」保留中文流程及完整英文 PDF 入口。牌面可右键放大，`F` 翻面、`R` 旋转。跟花合法性、能力效果、得墩、拜访结束与胜负均由玩家依规则执行。

## 素材与重建

`scripts/extract-for-northwood.py` 使用 pypdfium2 和 Pillow，按印刷裁切线提取中文组件，向内缩一个 PDF 点排除裁切标记，背面按双面长边的列镜像关系匹配。运行时传入源目录即可重建 `public/assets/for-northwood/` 的 WebP、规则副本及 `src/games/for-northwood-assets.js`。

```powershell
python scripts/extract-for-northwood.py 'D:\Art\PNP\为了北境森林'
```

全部素材与规则在本地提供，无运行时网络依赖；游戏、美术、规则及中文汉化的权利归各自作者，本次接入不改变原有授权。
