# 锡盔 / Tin Helm

[返回文档目录](../README.md)

在作品广场打开「锡盔」，选择十二种基础种族／职业组合之一。工具沿用工坊的自由桌面，辅助开局、双面地城探索、收牌、换层、属性与敌人奖励；战斗伤害、能量支付、事件、卡牌能力和物品消耗由玩家执行。

## 素材

来源为用户提供的 `D:\Art\PNP\锡盔锡王国\锡盔分享素材.pdf`，10页打印组件，没有完整规则书。使用 Poppler 与 Pillow 提取53份资产：9张双面种族／职业、14张双面地城、8张敌人、8张战利品、6张双面装备、3张双面事件参考、1张魅惑参考和4张属性轨道。偶数页按长边翻转镜像列与奇数页配对。重复的人类男性／炼金术师卡为替代画面，默认使用第一组人类卡，不额外当成独立角色。

## 开局与奖励内容

基础种族为鱼人、人类、鸦人和地精，基础职业为牧师、炼金术师、潜行者和掠夺者。同一张物理卡的正反面不能同时选择，因此有12种基础组合。初始生命与能量是种族数值加职业加值，也是当前生命／能量上限；食物取种族数值，声望和碎片为0。职业装备按中文卡面布置，人类开局必须在「敌人与物品」选择一张剩余双面装备的正面或背面后，才能开始探索。

「自选 / 奖励卡」可选择全部9种族与9职业中允许的72种组合，并重新开局；不会同时使用同一双面卡的两面。半身人自动从战利品中取出戒指。奖励冒险家需要同时持有铺盖卷和药剂，使用独立的战利品药剂卡，避免复制同一张双面物理卡。掠夺者等职业数值依本素材印刷值，未套用其他版本的职业值。

默认只将12张基础地城洗入牌库，每层6房间。奖励「深渊」与「隧道」留在独立牌位；自选窗口可为当前组合显式启用14张／每层7房间的变体。该变体不声称是基础规则要求。

自选组合会建立或更新独立的「自选」开局方案，重新开局时保留所选组合；操作可以撤销。十二个基础开局方案仍可在「基础组合」中选择。固定牌序的编辑开局保留玩家设置，不额外洗牌或重新生成牌。

## 探索流程

1. **查看牌库顶部地图**：地城始终地图朝上。选择「进入当前房间」使用第一张地图、第二张背面结果；选择「跳过」则第一张翻作结果、第二张作为地图。每次消耗两张。
2. **依图标结算**：从地图左侧图标开始，依序查结果卡相应行。营地与水源直接按规则处理，不使用结果表。参考卡双击或F查看背面。
3. **敌人图鉴**：在「敌人与物品」取对应敌人到战斗牌位，自动设置敌人生命为牌面生命加当前层数。先攻、监视者损失能量等特殊效果需手动结算。
4. **战斗与奖励**：投双骰只显示点数与点数差，不扣能量、不代算伤害。手动将敌人生命调整到0后点「击败并领奖」，自动记录声望、暗黑鼠食物、附身灵碎片，并将实体敌人归还图鉴。宝箱怪声望取层数。用卷轴直接消灭或避战时手动归还敌人，不点击击败奖励。
5. **战利品与消耗**：目录取用现有物品卡，不生成副本。药剂、萝卜等效果自行记录，已用物品拖进「已消耗物品」，不自动回到战利品。
6. **结束房间**：确认事件、战斗、陷阱等全部结算，再收回地图与结果卡，累计房间数；未归还的当前敌人会阻止收牌。
7. **下层**：完成本层全部房间，且全部地城完整收回后，消耗1食物；没有食物则扣3生命。层数加1，重洗地城，重置房间数。每层一次能力自行重置。第五层结束仍未集齐三枚碎片则结束失败。

生命为0显示失败；碎片为3且生命大于0显示成功。参考分为 `碎片×10 + 生命 + 能量 + 食物 + 声望×2 − 层数×2`。自由桌面允许手动纠正数值与摆放；提示不会证明全部能力、费用或战斗已合法结算。

## 属性、存档与验证

生命、能量、食物、声望、层数和敌人生命标记定位到原版轨道；滚轮调整后同步，拖至附近轨道数值可吸附。生命／能量上限随组合，食物上限5、声望15、碎片3。轨道版图平移或旋转后吸附仍按当前版图计算。0能量与0食物使用轨道末端额外位置表示。

辅助状态保存在开局物件／标记中，支持自动保存、导入导出、撤销与重做。动作先验证相关牌位是否完整、解锁及卡牌类型，拒绝重复取物、重复探索和不完整地城换层。

规则依据用户中文卡面、[作者商品页的探索与角色介绍](https://www.thegamecrafter.com/games/tin-helm)和[公开规则整理](https://github.com/marcmajcher/tin-helm/blob/main/RULES.md)。中文素材存在奖励组件和职业数值差异，卡面优先。复杂度取[BGG基础版](https://boardgamegeek.com/boardgame/347900/tin-helm)在2026-11-06的1.46快照。
