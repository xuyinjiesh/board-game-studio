# 聪明系列 / Clever

[返回文档目录](../README.md)

在作品广场打开「聪明系列」，选择绝顶聪明、双倍聪明、三倍聪明、四倍聪明，或前三代对应的挑战计分纸。七个方案各有原版纸张与对应六色骰；「规则」可打开四份原始中文规则。

## 纸面操作

点击格子划叉、圈记、打勾或擦除。数值格提供 0–12 快捷键盘，也可输入 0–999 后点击「填写数值」。倍数和折半由玩家计算，填写最终记在纸上的数值。三代蓝色中间印刷的 7 无须填写，四代绿色上下三角独立填写。

奖励轨道用 ○ 记录获得、× 记录用掉；奖励图标可用 ✓ 记录已结算。第 1 轮的轮数格已划叉，轮初奖励仍由玩家领取和圈出。挑战纸遵循印刷的条件和奖励；挑战纸 3 的配色不同，各区域按位置对应三代规则。

纸张默认锁定，落笔按钮仍可操作。Ctrl+滚轮缩放、空格+拖动平移。在编辑模式解锁后可移动、旋转、缩放或复制纸张，点击区域随图片变换；编辑模式停用落笔按钮。

## 单人流程辅助

1. 点击「投六颗骰」，选择一颗并按规则落笔。它移到已选区，点数严格更小的可用骰移到银盘，相等点数仍在骰池。
2. 投剩余骰，最多常规投掷三次；提前耗尽骰池也结束主动阶段。第三次选择后其余骰全部入盘。「本次无法落笔，跳过」仍消耗一次常规投掷。
3. 主动阶段落笔、奖励和额外骰全部结算后，点击「主动结束 · 模拟对手」。助手重投六骰，将最低三颗放入银盘。平局按投掷前更靠近银盘中心的骰优先，等距再按骰池顺序。
4. 从银盘选择一颗并落笔，或无法落笔时跳过。完成被动阶段后点击「完成本轮」。第六轮后助手停止推进，仍可补写纸面和核对分数。

工具栏显示蓝白之和，使用两颗骰当前的点数，包括已选和银盘上的骰。自由双击投掷、拖动和滚轮改点仍可用，但这些操作不推进助手，常规流程应使用助手按钮。助手不审核落笔条件、轮初奖励、狐狸来源和奖励连锁。

### 奖励

- 重投：选骰前消耗重投轨道的一个 ○，重投全部可用骰，不增加常规投掷次数。
- 额外骰：主动或被动回合末，先选中桌面的一颗骰，再点额外骰按钮，消耗一个 ○ 并自行落笔。同一颗骰每回合最多额外使用一次。按所给第一代中文单人规则，第一代禁用此按钮。
- 双倍聪明取回：下一次常规投掷前选中一颗银盘骰再取回，消耗一个 ○，该骰参加下一次投掷。第三次投掷后不能使用；未满三次而提前耗尽骰池时仍可取回。
- 三代任意点数、四代擦亮骰：按规则手动核销轨道，通过选中骰的操作面板或滚轮调整点数，再继续流程。

## 计分、多人和保存

第一代基础纸按记录估算黄色列分、蓝色叉数分、绿色进度、橙紫数值和与五处狐狸条件，可手动覆盖；清除手动修正后恢复估算。估分不检查非法跳格和落笔。

其余六张纸手动填写五区最终得分和狐狸数量。狐狸分、总分自动计算：`五区总和 + 最低区域分 × 狐狸数量`。区域分数允许 −999–999 的整数，狐狸数为 0–99；负分用于双倍聪明绿色差值。

多人可在编辑模式复制计分纸，共用六色骰，自由执行四、五或六轮。助手固定为单人六轮，不管理多人轮转和联机。复制的纸张可分别落笔，侧边助手与计分面板以第一张纸为主。

落笔、骰面、骰区、辅助回合与手工分数随进度自动保存，支持撤销、重做和 JSON 导出。重新开局或切换纸张恢复所选方案；游玩进度不覆盖已编辑的初始设置。

## 素材与实现

来源：用户提供目录 `D:\Art\PNP\聪明系列`。运行 `scripts/extract-clever.py <素材目录>`，需要 pypdfium2 和 Pillow，输出七张整页 WebP、四份原样复制的中文规则、程序绘制的十色六面骰图，以及资产清单 `src/games/clever-assets.js`。原文件不变。

`clever-sheets.js` 定义点击区域，`clever.js` 提供开局、助手、填写、估分与规则。通用桌面新增可选的 `boardOverlay`、`objectSignature`、`dialog`、`views` 和 `viewInsets`，分别支持纸面按钮、刷新、游戏窗口与工具栏空间预留；其他游戏保持原行为。
