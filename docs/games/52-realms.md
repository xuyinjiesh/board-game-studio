# 52王国 / 52 Realms: Adventures

[返回文档目录](../README.md)

本作使用用户提供的中文 PnP 地图和角色面板，接入工坊的自由操作桌面。规则作者为 Matthew Dunstan，基础中文规则标注翻译为白夜Wnight，补充规则标注翻译为 LEON。原素材版权归各自作者与汉化者，收集说明仅限个人分享游玩，不代表取得再分发或商业授权。

## 游戏组件

- 三张地下城地图：永恒游荡之魂的陵墓、永恒午夜森林、钟表匠的迷宫。
- 六位角色：野蛮人、法师、德鲁伊、堕落骑士、修补匠、猎人，各带独立的中文物品效果参考条。
- 一副无大小王的 52 张扑克牌。牌面与共用牌背由脚本使用字体绘制。
- 冒险者、敌人生命、敌人类型标记；德鲁伊增加形态标记，地图 3 增加时钟标记。
- 专用牌位：牌库、弃牌、敌人、奖励、创伤、战利品、四种物品、揭示区。地图 2 增加火炬和赏金；地图 3 增加上发条区；猎人增加独立收藏区。

地图、角色与参考条默认锁定，防止游玩时误拖。可在编辑模式解锁调整；右键可放大查看。底部工具栏可重新选择冒险、揭示卡牌与打开规则。全部素材与四份原始规则 PDF 均可本地使用。

## 开局

三张地图可以搭配任意角色，共 18 个开局方案。每次新开局：

1. 洗完整牌库。
2. 抽取两张非 A 作为物品，按花色放到对应牌位；同花色允许叠放。
3. 抽取非 A 作为装备，点数总和首次达到或超过 20 时停止；装备正面、竖直摆放。
4. 堕落骑士额外获得一张非 A 创伤。
5. 将准备时暂存的 A 洗回剩余牌库。地图 3 时钟标记位于 8，德鲁伊形态标记位于角色面板外。

J、Q、K 分别为 11、12、13，A 无等级。每个开局均保留全部 52 张不同的牌。新开局不覆盖已编辑的初始设置，游玩进度与方案可一同保存、导出和恢复。

自动准备只在标有 `realmsPrepare` 且仍持有完整 52 张扑克牌的来源牌库上执行；物品、创伤已有牌或其他位置已有扑克牌时，视为自定义布置，保留已编写的开局。固定牌序来源不再次随机洗牌，暂存的 A 按抽取顺序放回牌库底部。初始装备行位置由来源牌库的 `realmsEquipment` 定义。

## 游玩与辅助范围

- 将装备侧放表示耗尽，转回竖直表示就绪；物品、奖励、创伤与战利品自由拖放。
- 揭示按钮每次将一张牌放到揭示区。若是 A，保留这张 A 并提示玩家先结算地图诅咒，然后弃置 A、再抽替代牌。揭示区已有牌时按钮拒绝继续，避免覆盖未处理的结果。
- 敌人生命与时钟标记拖近轨道会吸附。轨道坐标随地图移动、缩放、旋转转换；其他标记自由摆放。
- 工具栏按牌位统计创伤与参考得分。普通物品每张 2 分、战利品等级相加、森林赏金为等级总和乘张数、猎人收藏为等级总和的两倍。达到创伤阈值会突出显示。
- 路线合法性、通行费、房间、敌人选择、战斗顺序、伤害、能力、物品、诅咒、时钟溢出及胜负由玩家依中文地图与规则执行。统计要求相关卡牌确实放入对应牌位，不会按散放卡牌的位置推断用途。

## 素材提取

执行 `scripts/extract-52-realms.py <素材目录>`，需要 Pillow 和 Windows 系统字体。素材目录中保留原始文件，脚本只向项目内写入：

- `public/assets/52-realms/`：三张地图、六张角色裁切、六张物品参考条、标准牌、共用牌背与规则 PDF。
- `src/games/52-realms-assets.js`：资产清单。

使用 `52 realms (2)/1.png`、`2.png`、`3.png` 作为地图。`a.png`、`b.png`、`c.png` 各包含两个头脚相对印刷的角色；左侧先旋转 180°，再裁切对应角色与参考条。不使用重复的 `地图.pdf` 或扫描合订本。原始 `中规.pdf` 和三份逐图规则 PDF 保持原样复制。

`tests/52-realms.test.js` 覆盖所有组合与多个随机种子、牌数守恒、首次达到装备阈值、准备阶段跳过 A、角色差异、固定与自定义开局、诅咒揭示、拒绝操作的无副作用、计分、轨道坐标与存档往返。
