# 迷你游侠 / Mini Rogue

[返回文档目录](../README.md)

## 入口与 DLC

在作品广场打开「迷你游侠」，先选择地图和 DLC，再选择角色。默认只有基础版：4 位角色、5 张首领、20 张房间。地牢在区域 2、4、7、10 遭遇首领，高塔在 3、6、8、10 遭遇首领。

可分别启用：

| DLC | 提供内容 |
| --- | --- |
| 诅咒深渊 | 3 位角色、2 张首领、7 张房间、26 张传说 |
| 古神扩展 | 骨士、死灵法师、3 张房间 |
| 死亡蝙蝠与赃物贩子 | 2 张推广房间 |
| 狼与熔炉 | 2 张推广房间 |

配置改变后点击角色才生效，关闭选择窗口不会修改正在游玩的桌面。相同配置保留编辑过的开局；改变配置重建内置角色方案并保留自建方案及其引用的素材。自建方案可能仍包含其原先使用的扩展牌。

## 桌面与开局

- 房间独立洗牌，随机取 8 张布成九宫格，只翻开左上入口。
- 右下出口的首领堆底是奥格之骸，其他首领洗牌后随机选 3 张放在上面，未选首领保留在备用区。
- 角色初始生命、护甲、经验、食物、金币和药剂按中文卡面设置。牧师带治疗、扩展盗贼带明目、女巫带剧毒；骨士从 2 经验和诅咒开始。
- 提供 3 颗角色骰、1 颗地城骰、1 颗中毒骰、1 颗诅咒骰。起始只使用 1 颗角色骰，经验 6 / 18 时分别使用第 2 / 3 颗；状态骰按是否中毒、诅咒决定加入骰池。
- 使用板件原图骰面：角色骰 1 为失误、5 / 6 带星，6 可暴击重掷；中毒与诅咒骰各 3 个触发面、3 个空白面。
- 角色板、地图、战役技能树、奖励／鬼魂参考卡、战斗姿态和对战规则均已提供。当前默认是单人冒险，双人可用编辑模式自行增设组件。

## 操作与边界

生命、经验、护甲、食物、金币、区域和怪物生命标记可拖到印刷轨道吸附，滚轮微调；面板移动、缩放和旋转后仍使用对应轨道。经验超过 23 的部分转成生命。两枚紫色药剂标记和物品次数标记自由摆放。

每个区域结束时，自行消耗食物或结算饥饿、翻回角色、推进区域标记，再点击「布置当前区域」。按钮回收所有散放或叠放的房间、洗混并重新发出 8 张，只翻开入口；不会扣补给或推进区域。将持有物品放入专用牌位，重布时会保留；用完后放回房间牌库。固定牌序的房间来源保留固定顺序。

到达首领区域时重布会翻开首领堆最上方的一张，底下首领保持隐藏。击败后自行把顶牌移入「已击败首领」，并依卡面结算奖励。奥格之骸的两阶段均由玩家执行。

诅咒深渊传说牌独立洗牌。「抽取传说」发到当前传说牌位，一次一张；处理完放入「已结算传说」，已用传说不洗回。区域重布不会触碰传说牌堆。

F 翻转角色卡记录技能冷却，翻转冒险者记录失明；R 旋转，右键放大，Ctrl+滚轮缩放，空格+拖动平移。房间效果、移动合法性、战斗、药剂、技能、战役和胜负由玩家按卡面及中文规则执行。

## 素材与提取

来源：用户提供目录 `D:\Art\PNP\迷你游侠中文版  带扩  含中规` 中的 18 页卡片 PDF、28 页中文规则和两张板件 JPG。原文件保持不变。

`scripts/extract-mini-rogue.py` 使用 pypdfium2 与 Pillow 渲染、裁切和分类，输出 `public/assets/mini-rogue/` 及 `src/games/mini-rogue-assets.js`。共 82 项资产：8 角色、8 首领、34 房间、26 传说、3 参考卡和 3 面板；另含 24 个骰面图片与中文规则副本。参考卡按双面配对，未把重复印刷的鬼魂、奖励或战斗姿态当作额外遭遇牌。

扩展归属依据中文卡面右下图标，并参照出版方的[诅咒深渊规则](https://www.nutspublishing.com/eshop/doc/minirogue/Depths-of-Damnation-EN-Rules.pdf)、[基础规则](https://www.nutspublishing.com/eshop/doc/minirogue/MR_Base_Booklet_Rules_EN.pdf)及[狼与熔炉说明](https://www.nutspublishing.com/eshop/mini-rogue-wolf-and-forge-en)核对。内容采用所提供 PnP 的版本；原游戏、插画、规则及中文汉化权利归各自作者和出版方。
